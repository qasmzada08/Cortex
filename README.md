# Cortex — AI-Powered Presentation Architect 🚀

**Cortex** is an intelligent, automated presentation builder designed to transform raw topics into structured, visually cohesive slide decks. Built using **Google Gemini** for analytical content structuring and **Nano Banana** for visual generation, Cortex streamlines the entire workflow from initial concept to presentation-ready slides.

> ⚠️ **Status:** Active Development (`v1.0-beta`) — Core presentation logic and visual prompt pipelines are currently being refined and expanded.

---

## ✨ Key Features

* **Intelligent Slide Structuring:** Uses Gemini's analytical capabilities to break down complex topics into logical slide flows (Introduction, Core Concepts, Key Takeaways) with concise, high-impact bullet points.
* **Automated Visual Direction:** Generates tailored, style-consistent image prompts for **Nano Banana** for every slide, ensuring visual harmony without text clutter.
* **No-Fluff Presentation Logic:** Enforces strict slide design rules (short bullet points, clear hierarchy, and balanced text-to-visual ratios) to avoid walls of text.
* **Rapid Prototyping:** Designed for students, analysts, and professionals who need to turn technical or academic ideas into structured presentations in minutes.

---

## 🛠️ Tech Stack & Architecture

* **Text & Logic Engine:** Google Gemini API (System-prompted for presentation architecture & storytelling)
* **Visual Generation:** Nano Banana (Illustrating slide concepts & clean compositions)
* **Frontend / Interface:** Built via Google AI Studio & iterative AI-assisted development
* **Version Control:** GitHub (`qasmzada08/Cortex`)

## 🚀 Getting Started

### Prerequisites
* A valid **Google Gemini API Key**
* Access to **Nano Banana** (or compatible image generation endpoint)
* Modern web browser (or Node.js / Python environment depending on local setup)

### Installation & Local Run
1. **Clone the repository:**
   `git clone https://github.com/qasmzada08/Cortex.git`
   `cd Cortex`
2. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your API key:
   `GEMINI_API_KEY=your_api_key_here`
3. **Install dependencies & run:**
   `npm install`
   `npm run dev`
